# when-bus

Singapore bus arrivals for nearby stops. React Native (Expo SDK libraries and
expo-router), Android only, built and shipped by
[`android-builder`](../android-builder/README.md). No EAS.

Package: `com.zadusz.whenbus`. Run `make help` for every command.

## Develop

```bash
npm install
make start        # Metro dev server
make run          # debug build on a device/emulator (needs JDK 17 + Android SDK)
make pair         # once per phone, then `make connect` to reconnect over Wi-Fi
```

JS changes hot reload through Metro. Rebuild with `make run` only after native
changes (new native dependency, `android/` edits).

## Emulator testing

A headless Android emulator (Pixel 7, Android 36 with Google APIs, so the
fused location provider works) runs on the Mac through
`android-builder/bin/android-emu`. It can be scripted from a terminal or by an
agent: GPS position, screenshots, UI text dump, taps.

```bash
make emu-setup                               # once
make build-home KIND=apk && make fetch-home KIND=apk
make emu-test                                # boots the emulator, installs, runs the smoke test
```

`scripts/emu-smoke.sh` checks that, at MacPherson Stn, the nearest stop, the
compass direction, bus destinations and the location line render. It then
moves the GPS 1 km and checks that the list follows with no taps, and
checks a refresh after resuming from the background. Use `make emu` and then
`make run` for a debug build with Metro on the emulator.

Driving it by hand: `android-emu geo 1.3262 103.8903`, `android-emu ui`,
`android-emu tap-text "Locate"`, `android-emu shot`, `android-emu home`,
`android-emu launch com.zadusz.whenbus`.

## Native project (`android/`)

`android/` is generated by `npx expo prebuild` and **committed**. It is the
source of truth for the Android binary. The homeserver builds it as is and
never runs prebuild.

Native settings in `app.json` (permissions, icons, splash, plugins) only take
effect when prebuild runs again. After changing them, or after an Expo SDK
upgrade:

```bash
npx expo prebuild --platform android --clean
git diff android/   # re-apply the local edits listed below, then commit
```

Local edits to keep across a prebuild:

- `android/app/build.gradle`: `versionCode` from `-PversionCode`, `versionName`
  from `appVersionName`, release signing from `ANDROID_KEYSTORE_*` env, no
  committed debug keystore.
- `android/gradle.properties`: `appVersionName=`.
- `android/.gitignore`: keystore and `signing.env` patterns.

## Release

```bash
make bump-version            # or VERSION=1.2.0 make bump-version
make release-home            # lint, signed AAB on the homeserver, upload to Play internal (draft)
```

- `versionName`: `appVersionName` in `android/gradle.properties`. `bump-version`
  keeps `app.json` and `package.json` in sync.
- `versionCode`: minutes since 2026-01-01 UTC, set by the homeserver build.
  This outranks the old EAS codes (last was 14).
- Upload keystore: `/srv/android-builder/apps/when-bus/secrets/` on the
  homeserver. It is the same key the EAS builds used. Back it up with
  `make keystore-backup`.
- A shipped build cannot be rolled back. Fix forward with a new build.
